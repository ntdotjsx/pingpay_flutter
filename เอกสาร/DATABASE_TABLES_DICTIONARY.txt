================================================================================
ระบบจัดการค่าใช้จ่ายร่วมกันและการชำระเงินผ่านพร้อมเพย์ (PingPay)
พจนานุกรมตารางฐานข้อมูลทั้งหมด 23 ตาราง (Database Dictionary & Schema Reference)
สถาปัตยกรรม: PostgreSQL 16 / Drizzle ORM (schema.ts)
================================================================================

หมวดที่ 1: ระบบผู้ใช้งาน การยืนยันตัวตน และความปลอดภัย (Users, Authentication & Security)
--------------------------------------------------------------------------------
1. ตาราง: users
   ชื่อภาษาไทย: ตารางข้อมูลผู้ใช้งานและโปรไฟล์
   คำอธิบาย: จัดเก็บข้อมูลบัญชีสมาชิก, รหัสประจำตัวสาธารณะ (User Code), ชื่อ-นามสกุลจริงภาษาไทย/อังกฤษ, เบอร์โทรศัพท์, ช่องทางรับเงิน (PromptPay ID/Type, TrueMoney Phone, Bank Account Number), คะแนนสะสม PingPay Points, บทบาท (user/developer) และสถานะบัญชี (active/suspended/banned)

2. ตาราง: auth_identities
   ชื่อภาษาไทย: ตารางข้อมูลอัตลักษณ์การเข้าสู่ระบบภายนอก
   คำอธิบาย: จัดเก็บข้อมูลเชื่อมโยงการยืนยันตัวตนด้วย Google Identity OAuth 2.0 (Google Subject ID)

3. ตาราง: user_credentials
   ชื่อภาษาไทย: ตารางข้อมูลรหัสผ่าน PIN และความปลอดภัย
   คำอธิบาย: จัดเก็บรหัสแฮช PIN 6 หลัก (Argon2id/Bcrypt), จำนวนครั้งที่กรอกผิดสะสม (failedAttempts) และเวลาปลดล็อคกรณีถูกระงับชั่วคราว (lockedUntil)

4. ตาราง: auth_sessions
   ชื่อภาษาไทย: ตารางข้อมูลเซสชันการใช้งานอุปกรณ์เดียว
   คำอธิบาย: จัดเก็บ Refresh Token Hash, ข้อมูลอุปกรณ์ (Device Info), IP Address และวันหมดอายุเซสชัน เพื่อควบคุมความปลอดภัยให้ใช้งานได้เพียง 1 อุปกรณ์ต่อบัญชี (Single Active Device Session Policy)

5. ตาราง: device_tokens
   ชื่อภาษาไทย: ตารางข้อมูลอุปกรณ์และโทเคนแจ้งเตือน
   คำอธิบาย: จัดเก็บ Firebase Cloud Messaging (FCM) Device Registration Token, แพลตฟอร์ม (Android/iOS), รุ่นอุปกรณ์, และเวอร์ชันระบบปฏิบัติการ สำหรับส่ง Push Notification

6. ตาราง: consent_records
   ชื่อภาษาไทย: ตารางประวัติการยินยอมนโยบาย PDPA
   คำอธิบาย: บันทึกประวัติการกดยอมรับนโยบายคุ้มครองข้อมูลส่วนบุคคล (PDPA Consent) หมายเลขเวอร์ชันนโยบาย, IP Address และวันเวลาที่กดยอมรับ

7. ตาราง: otp_verifications
   ชื่อภาษาไทย: ตารางข้อมูลรหัสผ่านใช้ครั้งเดียว (OTP)
   คำอธิบาย: จัดเก็บรหัสแฮช OTP 6 หลัก, อีเมลผู้รับ, วัตถุประสงค์ (pin_reset), จำนวนครั้งที่กรอกยืนยัน และเวลาหมดอายุ 15 นาที สำหรับรีเซ็ตรหัส PIN เมื่อลืมรหัส

8. ตาราง: security_events
   ชื่อภาษาไทย: ตารางบันทึกเหตุการณ์ความปลอดภัย
   คำอธิบาย: บันทึกเหตุการณ์ความปลอดภัย เช่น การสุ่มรหัส PIN เกินจำนวน (pin_brute_force) และการพยายามเข้าสู่ระบบที่ผิดปกติ


หมวดที่ 2: ระบบความสัมพันธ์และเครือข่ายเพื่อน (Friends & Social)
--------------------------------------------------------------------------------
9. ตาราง: friendships
   ชื่อภาษาไทย: ตารางข้อมูลความสัมพันธ์เพื่อน
   คำอธิบาย: จัดเก็บความสัมพันธ์และคำขอเป็นเพื่อนแบบ 2 ทิศทาง (ผู้ส่ง requester_id, ผู้รับ addressee_id, สถานะ: pending, accepted, blocked, rejected, cancelled, เวลาตอบรับ และเวลาลบเพื่อนแบบ Soft Delete)


หมวดที่ 3: ระบบบิลค่าใช้จ่ายและการจัดสรรยอดหนี้ (Bills & Splitting)
--------------------------------------------------------------------------------
10. ตาราง: bills
    ชื่อภาษาไทย: ตารางข้อมูลบิลค่าใช้จ่ายและผลสแกน OCR
    คำอธิบาย: จัดเก็บข้อมูลหัวบิล, เจ้าของบิล (ผู้สำรองจ่าย/เจ้าหนี้), ยอดเงินรวมปัจจุบัน (total_amount), ยอดเริ่มต้นถาวรตอนสร้างบิล (original_total_amount - เพดานยอดเงินสูงสุด), ภาพถ่ายใบเสร็จรับเงิน, ผลลัพธ์ข้อมูลดิบจาก AI OCR (ocr_raw_data), รายการแจกแจงภาษี/ค่าบริการ (items_breakdown) และสถานะบิล

11. ตาราง: bill_items
    ชื่อภาษาไทย: ตารางข้อมูลรายการหนี้รายบุคคลประจำบิล
    คำอธิบาย: จัดเก็บรายการหนี้ของเพื่อนแต่ละคนในบิล, ยอดหนี้เริ่มต้นถาวร (original_amount), ยอดหนี้ปัจจุบัน (current_amount), ยอดเงินที่ชำระแล้ว (amount_paid), ยอดเงินที่ยกหนี้ให้ (amount_written_off), สถานะยอมรับหนี้ (is_acknowledged) และสถานะล็อคการแก้ไขยอดเงิน (is_locked)


หมวดที่ 4: ระบบการชำระเงิน การตรวจสลิป และสมุดบัญชี (Payments & Financial Ledger)
--------------------------------------------------------------------------------
12. ตาราง: payments
    ชื่อภาษาไทย: ตารางข้อมูลการชำระเงินและสลิปโอนเงิน
    คำอธิบาย: จัดเก็บประวัติงวดการชำระเงิน (เต็มจำนวน/ผ่อนชำระ, ลำดับงวด), สแนปช็อต Dynamic PromptPay QR Payload (EMVCo), ภาพถ่ายสลิปโอนเงินธนาคาร, รหัส SHA-256 Hash ของสลิปสำหรับป้องกันสลิปซ้ำ, และสถานะการยืนยัน/ปฏิเสธของเจ้าหนี้

13. ตาราง: payment_verifications
    ชื่อภาษาไทย: ตารางข้อมูลประวัติการตรวจสอบสลิป EasySlip
    คำอธิบาย: จัดเก็บบันทึกประวัติการเรียก EasySlip API v2 ตรวจสอบสลิปธนาคารแบบเรียลไทม์ (ชื่อผู้โอน-ผู้รับ, เลขบัญชี, ยอดเงินจริงที่ตรวจพบ, หมายเลขอ้างอิง Ref No., วันเวลา และรหัสข้อผิดพลาด)

14. ตาราง: financial_transactions
    ชื่อภาษาไทย: ตารางสมุดบัญชีแยกประเภทธุรกรรมทางการเงิน
    คำอธิบาย: สมุดบัญชีแยกประเภทแบบบันทึกเพิ่มอย่างเดียว (Append-Only Financial Ledger) สำหรับบันทึกความเคลื่อนไหวทางการเงินทุกรายการ (debt_created, debt_adjusted, payment, refund, write_off) เพื่อตรวจสอบสมดุลทางการเงิน (Financial Invariants)

15. ตาราง: edit_logs
    ชื่อภาษาไทย: ตารางประวัติการแก้ไขบิลและปรับปรุงยอดหนี้
    คำอธิบาย: บันทึกประวัติการเปลี่ยนแปลงแก้ไขข้อมูลบิล (bill_created, bill_amount_edited, bill_item_edited, debt_written_off, bill_cancelled, friend_added, friend_removed) ค่าเดิม (previous_value), ค่าใหม่ (new_value), ผู้กระทำ และเหตุผล


หมวดที่ 5: ระบบข้อพิพาททางการเงินและการตรวจสอบหลังบ้าน (Disputes & Audit Logs)
--------------------------------------------------------------------------------
16. ตาราง: disputes
    ชื่อภาษาไทย: ตารางข้อมูลข้อพิพาททางการเงินและหลักฐานสองฝ่าย
    คำอธิบาย: จัดเก็บรายการข้อพิพาทเรื่องยอดหนี้ระหว่างผู้ใช้, เหตุผลการคัดค้านและภาพถ่ายหลักฐานของลูกหนี้ (evidence_url), คำชี้แจงและภาพถ่ายหลักฐานแก้ต่างของเจ้าหนี้ (creditor_evidence_note, creditor_evidence_url), เวลาที่เจ้าหนี้ตอบกลับ (creditor_responded_at), และผลการตัดสินชี้ขาดของผู้ดูแลระบบ (resolved_paid, resolved_written_off, resolved_rejected)

17. ตาราง: admin_action_logs
    ชื่อภาษาไทย: ตารางบันทึกประวัติการปฏิบัติงานของผู้ดูแลระบบ
    คำอธิบาย: บันทึก Audit Trail ทุกการกระทำของผู้ดูแลระบบ/นักพัฒนาบน Developer Console (การระงับ/แบนบัญชี, การตัดสินข้อพิพาท, การดูประวัติธุรกรรม, การบรอดแคสต์) พร้อมเหตุผลและข้อมูลอ้างอิง

18. ตาราง: suspicious_activity_logs
    ชื่อภาษาไทย: ตารางบันทึกพฤติกรรมน่าสงสัยและการทุจริต
    คำอธิบาย: จัดเก็บบันทึกพฤติกรรมผิดปกติและการทุจริต เช่น การใช้สลิปโอนเงินซ้ำ (duplicate_slip), การใช้หลายบัญชีจาก IP เดียวกัน (multi_account_ip) ซึ่งจะไม่ถูกลบอัตโนมัติ

19. ตาราง: activity_logs
    ชื่อภาษาไทย: ตารางบันทึกกิจกรรมการใช้งานทั่วไป
    คำอธิบาย: บันทึกกิจกรรมทั่วไปของผู้ใช้งานในระบบ โดยมีกระบวนการล้างข้อมูลประวัติเก่าอัตโนมัติทุก 1 เดือน


หมวดที่ 6: ระบบคิวงานแจ้งเตือนและการส่งมอบ (Notifications & Outbox)
--------------------------------------------------------------------------------
20. ตาราง: notification_outbox
    ชื่อภาษาไทย: ตารางคิวงานส่งข้อความแจ้งเตือนระดับระบบ
    คำอธิบาย: จัดเก็บคิวข้อความแจ้งเตือนเบื้องหลังตามรูปแบบ Outbox Pattern, Deduplication Key สำหรับป้องกันการส่งแจ้งเตือนซ้ำซ้อน, สถานะคิวงาน (PENDING, PROCESSING, SENT, FAILED, SKIPPED) และจำนวนครั้งที่พยายามส่งซ้ำ

21. ตาราง: notification_deliveries
    ชื่อภาษาไทย: ตารางบันทึกผลการส่งมอบการแจ้งเตือนไปยัง Firebase
    คำอธิบาย: จัดเก็บบันทึกผลลัพธ์การส่งข้อความแจ้งเตือนระดับอุปกรณ์ผ่าน Firebase Cloud Messaging (FCM HTTP v1) Response Payload และ Error Message


หมวดที่ 7: ระบบร้านค้าของรางวัลและการแลกคะแนนสะสม (Rewards & Gamification)
--------------------------------------------------------------------------------
22. ตาราง: reward_items
    ชื่อภาษาไทย: ตารางแคตตาล็อกสินค้าของรางวัล
    คำอธิบาย: จัดเก็บรายการของรางวัลสำหรับแลกแต้ม, จำนวนคะแนนที่ต้องใช้ (points_cost), หมวดหมู่สินค้า (physical/voucher/gadget), ภาพสินค้า, จำนวนสต็อกคงเหลือ และสถานะเปิดใช้งาน

23. ตาราง: reward_redemptions
    ชื่อภาษาไทย: ตารางประวัติการแลกของรางวัลและการจัดส่ง
    คำอธิบาย: จัดเก็บประวัติการทำรายการแลกของรางวัล, จำนวนแต้มที่ถูกหัก, ข้อมูลชื่อ-เบอร์โทรศัพท์-ที่อยู่จัดส่งพัสดุ, สถานะการจัดส่ง (pending_delivery, shipped, delivered, cancelled) และหมายเลขติดตามพัสดุ (tracking_number)
